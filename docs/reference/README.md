# Reference

Diátaxis section: **information-oriented**.

Reference is for looking things up. Precise, neutral, and exhaustive within
its scope. No tutorials, no opinions, no narrative.

## Conventions

- One file per cohesive topic (CLI command, config schema, public API)
- Tables and lists over prose
- Stable URLs — readers bookmark these
- Match the structure of the thing being documented (don't impose a story)
