# How-to guides

Diátaxis section: **task-oriented**.

How-to guides assume the reader already knows the basics and is trying to
solve a specific problem. They are recipes, not tutorials.

## Conventions

- One file per problem; title states the problem ("How to rotate a secret")
- Imperative voice, numbered steps
- Each step is independently verifiable
- Don't explain *why* — link to an explanation page if needed
