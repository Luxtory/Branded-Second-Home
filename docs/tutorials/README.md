# Tutorials

Diátaxis section: **learning-oriented**.

Tutorials take a complete beginner from zero to a first working result.
They are guided, hand-held, and prioritize getting the user to a small win
fast — not exhaustive coverage.

## Conventions

- Each tutorial is a single Markdown file in this folder
- Title = the concrete outcome the user achieves
- Uses imperative voice ("Create the database", "Run the test")
- Every command shown should work as-is when copy-pasted
- Length: 15–45 minutes of reader time
